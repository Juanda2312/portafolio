Full stack · Marketplace multi-vendedor

E-Commerce Marketplace Gamer

Marketplace multi-vendedor de productos gaming (periféricos, mobiliario de setup, juegos físicos, licencias digitales y combos), construido en equipo para Programación Avanzada / Ingeniería de Software en la Universidad del Quindío. Full stack con Angular, Spring Boot y MariaDB, bajo Arquitectura Hexagonal y Domain-Driven Design.

  • Modelo de dominio rico: raíces de agregado, objetos de valor como records de Java y reglas de negocio protegidas (stock nunca negativo, reembolso dentro de 48 h, una reseña por compra).
  • 37 casos de uso: compras, catálogo, combos, reseñas y puntos, wishlist, notificaciones, cuentas y reportes.
  • Seguridad con Spring Security y JWT, roles COMPRADOR y VENDEDOR, contraseñas con BCrypt y la identidad del usuario siempre tomada del token.
  • API REST documentada con Swagger, con búsqueda paginada de catálogo y reportes de ventas resueltos en la base de datos.
  • Pruebas con @DataJpaTest, endpoints protegidos (401 / 403 / 201) y una prueba de integración de punta a punta con MockMvc.

Full stack · Gestión inmobiliaria

PropTech

Sistema full stack que va más allá del CRUD: gestiona inmuebles, clientes, asesores, visitas y operaciones, y analiza el comportamiento comercial. Sus colecciones principales son implementaciones propias, sin java.util.

  • Arquitectura en capas: frontend en Angular 17 y API REST con Spring Boot 3 (Java 21), documentada con Swagger UI.
  • Estructuras de datos con propósito: árbol AVL para precios y rankings, grafo con BFS para relaciones cliente–inmueble, pila para deshacer y colas FIFO y de prioridad para visitas y alertas.
  • Motor de recomendaciones con puntaje de 0 a 100, alertas automáticas y detección de comportamientos inusuales.
  • PropBot: asistente con IA (LLM vía OpenRouter) que responde con datos en vivo de la plataforma; las consultas pasan por un proxy del backend, así la clave nunca llega al navegador.
  • Desplegado en producción: frontend en Vercel y API en Docker sobre Render, con CORS restringido y configuración por variables de entorno.

Móvil · App Android sin conexión

ListaMercado

App Android 100% offline para organizar el mercado: gestiona productos y supermercados, arma la lista con totales por supermercado y controla un presupuesto con el saldo restante. Hecha con Flutter, sin internet.

  • Búsqueda inteligente, sin distinguir mayúsculas ni tildes, y filtro por supermercado.
  • Dos vistas, plana y por supermercado, con tachado sincronizado entre ambas.
  • Deslizar para quitar ítems con opción de deshacer, y presupuesto opcional con saldo en verde o rojo.
  • APK de release firmado, sin permiso de internet y con todos los datos guardados localmente.

Bases de datos · App de escritorio

Sistema de Gestión de Proveedores y Productos

Proyecto final de Bases de Datos I en la Universidad del Quindío: aplicación de escritorio que registra qué proveedores pueden suministrar qué productos, hecha sin frameworks (biblioteca estándar de Python y librerías puntuales) sobre una base de datos relacional normalizada (SQL Server en el proyecto original y SQLite en la demo ejecutable). Proyecto en equipo.

  • Diseño relacional: 9 tablas normalizadas, diagrama entidad-relación, diagrama relacional y diccionario de datos; la relación muchos a muchos proveedor–producto se resuelve con una tabla intermedia.
  • SQL avanzado: consultas JOIN de varias tablas y subconsultas, todas parametrizadas para evitar inyección SQL.
  • Acceso por roles (administrador, usuarios tradicionales y esporádicos), contraseñas con PBKDF2 y bitácora de entradas y salidas.
  • Reportes en PDF con filtros elegidos por el usuario, arquitectura en tres capas y una demo ejecutable para Windows, Linux y macOS que se abre sin instalar nada.
